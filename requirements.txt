# ── Pinned transitive dependencies (security-sensitive) ───────────────────────
# These are pulled in transitively (by fastapi, python-jose[cryptography],
# httpx/aiohttp). Left unpinned, each build resolved a different version, so a
# CVE could silently (re)enter the image. Pinned to the versions validated in
# development. Bump deliberately, not by accident.

cryptography==48.0.0      # python-jose[cryptography] / TLS backend
anyio==4.14.0             # starlette/httpx async core
h11==0.16.0               # httpx HTTP/1.1 backend; >=0.16 clears request-smuggling CVE-2025-43859
certifi==2026.6.17        # CA bundle — keep current so revoked roots are dropped
ecdsa==0.19.2             # python-jose dep; UNUSED here (auth is HS256/HMAC). See note below.
# NOTE: `ecdsa` has no fix for the Minerva timing side-channel (CVE-2024-23342);
# the maintainers consider it out of scope. It is safe here only because the
# admin JWT path uses HS256 (HMAC), never ECDSA. If ECDSA/EC-JWT is ever
# introduced, migrate off python-jose (e.g. to PyJWT) to drop this dependency.
